# DemoHub · 本地静态 HTML 托管系统

## 系统作用与用途

DemoHub 用来在本机集中托管、分享和整理静态网页。演示原型、导出的 HTML 报告、离线网页和网页归档不需要再逐个用浏览器打开文件，上传后即可得到固定访问链接，并在统一后台里管理。

它适合个人或小团队在内网使用：把零散的静态成果收进一个站点，按门户导航给他人浏览，同时用账号审批控制谁能上传和管理。系统不运行服务端业务逻辑，只托管静态内容。

主要用途：

- 发布 HTML、文件夹、ZIP 压缩包和 MHTML 网页归档，并生成可分享的访问地址。
- 用门户导航把多个站点整理成入口页，方便按主题对外展示。
- 在文件管理中维护站点目录、资源和入口页。
- 通过用户注册审批区分管理员和普通用户，避免未授权人员改动内容。
- 查看上传和访问情况，便于整理正在使用的演示页面。

数据默认保存在本机 `data` 目录，包含站点文件和 SQLite 数据库。服务默认只监听本机，不对外公开。

## 运行

```bash
npm install
npm start
```

打开：

```text
http://127.0.0.1:3000/admin
```

默认监听 `127.0.0.1:3000`，本机可直接使用。需要局域网或公网访问时，可在 `src/config.js` 中修改 `host` 为 `0.0.0.0`，或通过反向代理对外暴露。

## 首次使用

- 第一次访问系统时，需要先注册第一个账号。
- 第一个注册账号会自动成为已审批管理员。
- 后续注册账号默认为待审批状态，必须由管理员在"用户管理"页面审批后才能登录使用。
- 如果在"系统设置 → 用户注册"关闭了注册开关，登录页将不再显示注册入口，且 `/register` 也会被拒绝。系统没有任何用户时，这个开关不会阻止创建第一个管理员。

## 上传与访问

### 支持的上传类型

- 单文件：`.html` / `.htm`（保存为 `index.html`）、`.zip`、`.mhtml`。
- 文件夹：通过浏览器文件夹选择器上传，保留子目录结构。
- 资源文件：`.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.ico`、`.bmp`、`.svg`、`.pdf`，可在文件管理中直接预览。

### 主文件选择

- ZIP 和文件夹上传时，系统自动在根目录寻找 `index.html`。
- 根目录没有 `index.html` 时，必须手动从文件列表中选择主文件；主文件也可以位于子目录。
- 子目录入口通过站点根 URL 302 重定向，无需依赖 `express.static` 的默认文档。

### MHTML 解包

- `.mhtml` 文件会被自动解包为 multipart 静态站点，附件按内容类型保存，HTML 内的引用路径会被改写。
- 解包后的站点可直接预览，原始 MHTML 不对外暴露。

### 访问链接

- 静态访问链接格式：`http://127.0.0.1:3000/sites/{siteId}/`。
- 系统设置里可以配置"分享地址"，例如 `http://192.168.1.11:3000` 或 `https://your.domain`。配置后，网站管理、文件管理和仪表盘上展示、复制、打开的链接会固定使用这个地址。
- 留空则跟随当前访问地址：本机用 `127.0.0.1` 管理，局域网分享时改用 `192.168.x.x` 打开后台即可。
- 管理页预览、目录树和门户内嵌站点仍使用当前访问地址，避免域名未解析时无法预览。

## 文件管理

- 文件管理页列出当前站点的完整目录树，支持下载、删除、重命名和目录创建。
- 支持上传图片、PDF、SVG 等资源文件，并在当前页面内预览。
- 目录树和文件列表都按类型显示 SVG 图标，图标集中在 `src/public/file-icons/`。
- 资源文件的响应头已加严格 CSP，防止同域脚本执行。
- 顶部搜索框支持按名称过滤，回车直接打开第一条，按 Esc 清空。

## 网站管理

- 网站管理页顶部搜索框可按站点名称或访问地址过滤。
- 门户列表（导航页）会为每个门户按固定规则分配默认图标，图标底色跟随该门户主题色。

## 用户管理

- 管理员可直接在"用户管理"页点击"新增用户"创建账号，创建后立即可用（状态为已审批）。
- 通过公开注册入口创建的账号默认状态为待审批，需要管理员手动审批。
- 最后一个已审批管理员不能被拒绝或禁用。

## 系统设置

- **基本信息**：系统名称、副标题。
- **Logo**：大 Logo / 小 Logo、导航栏显示方式。
- **主题**：默认浅色或深色。
- **用户注册**：开关是否允许公开注册（首个管理员不受此限制）。
- **分享地址**：可留空；填写后列表链接固定使用该地址，便于局域网或域名分享。
- **存储位置**：数据目录可自定义，修改后重启生效。浏览按钮在页面内列出服务器目录，Windows 从磁盘列表开始，Linux 从根目录开始。

## 数据目录

- 默认数据目录为 `data/`，保存上传文件和 SQLite 数据库。
- SQLite 使用 better-sqlite3，迁移脚本在 `src/migrations/`。
- 存储位置自定义后，下次启动时生效；当前目录不会自动迁移数据，需要手动复制。

## 技术栈

- 后端：Node.js + Express。
- 数据库：better-sqlite3，键值配置表和迁移版本表。
- 上传处理：Multer（表单）、yauzl（ZIP）、自定义 MHTML multipart 解析器。
- 密码存储：scrypt，会话 Cookie 7 天有效，带 CSRF Token。
- 前端：管理页服务端渲染（EJS 风格模板），纯 CSS 和原生 JS，无构建步骤。

## 限制

- 默认只监听 `127.0.0.1`。
- 单个上传文件最大 50MB。
- ZIP 文件最多 1000 个条目。
- ZIP 解压后最大 200MB。
- ZIP 单文件最大 25MB。
- 目录浏览仅列出服务器上可读取的子目录，单个目录最多 300 项。
- 用户密码采用 scrypt 存储，会话 Cookie 有效期 7 天。
